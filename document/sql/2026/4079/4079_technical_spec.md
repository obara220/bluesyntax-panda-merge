## 一、概述

### 1.1 目标
在操盘风控后台结算管理的 PA 报球板中，新增**乒乓球**球种的报球板功能，支持局盘比分录入、事件录入、赛事统计及操作日志记录，并将所有操作数据下发至比分中心。

### 1.2 改动范围
| 模块 | 改动类型 | 说明 |
|------|---------|------|
| 操盘风控后台 | 新增页面/功能 | PA 报球板 → 乒乓球模块 |
| 比分中心 | 数据接入 | 接收乒乓球赛事阶段、事件、比分数据 |
| 客户端（Web/iPad） | 数据展示 | 赛事消息、赛果展示、历史注单等 |
| 结算审核 1.0 | 数据接入 | 比分变更确认后结算 |
| 事件审核 | 数据接入 | 接收报球板操作事件 |

## 二、赛制与基础规则

### 2.1 赛制选项
- **best5 of 3**（五局三胜）：最多选择到 SET5
- **best7 of 5**（七局五胜）：最多选择到 SET7（默认）

### 2.2 局分获胜条件
每局切换时需同时满足：
1. 至少有一方得分 ≥ 11
2. 两队分值差 ≥ 2

### 2.3 发球规则
- 默认 H 方（主队）发球第一个球
- 每局正常发球顺序：每人连续发 2 分
- 发球计数：0/2 表示当前发球方已发 0 分，本局最多发 2 分后换发球方
- 进入报球板和切换小局时，可选择发球方及当前为第几次发球

## 三、赛事状态机

### 3.1 状态定义

| 状态 | match_status id | 说明 |
|------|----------------|------|
| 默认未开赛 | 0 | 初始状态，除"比赛开始"外所有操作禁点 |
| 比赛开始 | 8 | 赛事阶段切换为 SET1，开始计时 |
| SET1 | — | 第一局进行中 |
| SET2 | 9 | 第二局开始，比分清 0，开始计时 |
| SET3 | 10 | 第三局开始 |
| SET4 | 11 | 第四局开始 |
| SET5 | 12 | 第五局开始 |
| SET6 | 441 | 第六局开始 |
| SET7 | 442 | 第七局开始 |
| 小局休息 | 301~306 / 100 | 第一~七局休息（id:301~306），第七局休息 id:100 |
| 比赛中断 | 80 | 赛事阶段显示"比赛中断"，所有事件禁点 |
| 比赛重开 | 局 id | 回到中断前的局，恢复中断前赛事状态 |
| 比赛暂停 | — | 停止计时，赛事阶段不变，仍可操作事件 |
| 比赛继续 | — | 开始计时，赛事阶段不变 |
| 比赛结束 | 999 | 所有 icon 禁点，显示赛事阶段：比赛结束 |

### 3.2 状态转换规则

```
默认未开赛 (id:0)
    │
    ├─[比赛开始, id:8]──→ SET1 ──→ SET2 (id:9) ──→ SET3 (id:10) ──→ SET4 (id:11) ──→ SET5 (id:12) ──→ SET6 (id:441) ──→ SET7 (id:442)
    │                        │                                                                    │
    │                        └─[小局休息, id:301~306/100]──────────────────────────────────────────┘
    │
    └─[比赛中断, suspension, id:80]──→ [比赛重开, suspension_over, id:局id]──→ 回到中断前赛事阶段

比赛暂停 (timeout) / 比赛继续 (timeout_over)：在任意可进行事件的阶段内切换，不改变赛事阶段
比赛结束 (999)：终态，所有 icon 禁点
```

## 五、操作元件规格

| 元件 | 行为 | 状态约束 |
|------|------|---------|
| 赢分 | 点击后该队分数 +1，增加 table_tennis_score_change 事件 | 发球后仅发球方可点击赢分；一次发球只能点击一次赢分 |
| 发球 | 点击后增加 current_serve_tabletennis 事件，发球计数 +1 | 未开赛不可点；已发球的队伍发球计数到 2/2 后可再次发球 |
| 重新发球 | 点击后增加 re_serve 事件 | 仅发球方在发球后且对方未赢分时可点击 |
| 黄牌 | 点击后增加 yellow_card 事件，比分无变化 | 发球后可点击 |
| 红牌 | 点击后增加 red_card 事件，自动为对方 +1 分 | 发球后可点击；可删除 |
| 黄红牌同手 | 点击后增加 yellowred_card_same_hand 事件，弹出二次确认，确认后比赛进入结束状态（非小局结束） | 发球后可点击；比分无变化 |
| 比赛开始 | 点击后 match_status→id:8，赛事阶段变为 SET1，按钮变为比赛结束 icon，开始计时 | 仅未开赛状态可点击 |
| 比赛结束 | 点击后 match_status→999，所有 icon 禁点 | 仅比赛中可点击 |
| 比赛阶段（显示） | 比赛开始后显示当前赛事阶段，不可点击；小局休息期间变为可点击 | — |
| 加速模式 | 点击后进入加速模式，该按钮不可再点，持续到该局结束 | 仅比赛中可点击；加速模式生效后每人发球次数变为 1 分 |
| 比赛中断 | 点击后 match_status→suspension id:80，所有事件禁点，显示"赛事中断" | 仅比赛中可点击 |
| 比赛重开 | 点击后 match_status→suspension_over id:局id，恢复中断前赛事 | 仅比赛中断状态可点击 |
| 比赛暂停 | 点击后 timeout，停止计时，仍可操作事件，按钮变为"继续" | 仅比赛中可点击 |
| 比赛继续 | 点击后 timeout_over，开始计时，按钮变为"暂停" | 仅比赛暂停状态可点击 |

## 六、发球状态机

### 6.1 发球计数逻辑
- 默认：H 方发球第一个球，计数 0/2
- 每点击一次"发球"，发球计数 +1
- 计数达到 2/2 后，发球权切换至对方
- 加速模式下：每人连续发 1 分（计数 0/1）

### 6.2 各状态下可点击事件

| 比赛状态 | 可点击事件 |
|---------|-----------|
| 未开赛 | 仅"比赛开始" |
| 已开赛，等待发球（发球计数 0/2 或 0/1） | 发球 |
| 已发球，发球方发球 | 重新发球（仅发球方）、赢分（仅发球方）、黄牌、红牌、黄红牌同手 |
| 已发球，非发球方 | 赢分、黄牌、红牌、黄红牌同手 |
| 小局休息 | 赛事阶段切换（进入下一局）、比赛暂停 |
| 比赛中断 | 比赛重开 |
| 比赛暂停 | 所有常规事件（比赛继续除外） |
| 比赛结束 | 无 |

## 七、报球板界面规格

### 7.1 进入报球板弹框

| 字段 | 选项/默认值 | 说明 |
|------|-----------|------|
| 赛制 | best7 of 5（默认）/ best5 of 3 | 选择后 SET 选项联动：best5 of 3 最多到 SET5 |
| SET | SET1（默认）~ SETn | 选择几局则直接进入几局的比赛阶段 |
| 小局比分 | 0-0（默认） | 可点击 + 加 1 分、- 减 1 分，可手动填写 |
| 发球方 | H 方（默认） | 若数据商有信息则默认填入，支持修改 |
| 当前发球次数 | 0/2（默认） | 同上 |

### 7.2 切换小局弹框
- 触发时机：报球过程中需要切换小局时弹出（不包括小局开始按钮，只出现在赛事阶段切换下拉选择未来局时）
- 字段与进入弹框相同：小局比分（默认 0-0）、发球方、当前发球次数

### 7.3 报球板布局
```
┌─────────────────────────────────────────────────────────┐
│  操作区（赢分/发球/黄牌/红牌/...）                        │
├──────────────────────┬──────────┬───────────────────────┤
│  赛事信息（滚动条浏览） │ 比分变动栏 │  赛事统计 / 操作日志   │
│  （主队 vs 客队）      │  （可编辑） │                      │
└──────────────────────┴──────────┴───────────────────────┘
```

### 7.4 比分变动规则
- 可对当前阶段及之前所有阶段进行变更比分
- 点击编辑后进入编辑模式，点击比分框可输入，可加减分
- 修改比分后需确认，并发送至融合比分中心
- 以下页面需做比分变更后的确认：事件审核页面、结算审核 1.0 页面、入口处、操盘后台球种页面、客户端展示赛果页面、客户端列表页、客户端详情页、客户端历史注单、注单中心、未来的 A01 比分面板

### 7.5 比分统计显示
- 上下两行显示，主队（H）和客队（A）各一行
- 显示内容为事件在不同 SET 阶段的次数
- 小局比分全场显示为局比分，每一局显示为局内比分

## 十、关键技术约束

| 约束项 | 说明 |
|--------|------|
| 局分切换校验 | 每局切换时，至少有一方 ≥ 11 分且分值差 ≥ 2，不满足则不允许切换 |
| 加速模式不可逆 | 加速模式一旦点击不可撤销，持续到该局结束 |
| 红黄牌同手终态 | 确认后比赛直接进入"比赛结束"状态（999），非小局结束 |
| 比赛中断期间 | 任何事件不可点击，赛事阶段不可切换，仅"比赛重开"可用 |
| 比赛暂停期间 | 仍可进行操作（事件按钮可用），仅计时停止 |
| 发球计数联动 | 发球后赢分仅发球方可操作；一次发球只能点击一次赢分 |
| 红牌加分 | 红牌操作自动为对方 +1 分，并记录红牌数 |
| 数据商信息代入 | 若比赛已开始，进入报球板时默认代入数据商提供的赛制、阶段、比分、发球方及发球次数信息，支持手动修改 |
